KNOWN LIMITATIONS
================================================================================

1. Only handles "Employee" as party type
   - Sufficient for payroll context
   - Future: Could extend for Supplier/Customer if needed

2. Assumes single currency per payroll entry
   - Matches standard ERPNext behavior
   - Multi-currency needs testing

3. Caching is instance-level only
   - Sufficient for single payroll processing
   - Cache cleared when payroll entry reloaded

================================================================================
SUPPORT & TROUBLESHOOTING
================================================================================

Common Issues:

Issue: JV not created
  → Check Error Log doctype
  → Look for: "No salary components found"
  → Verify: Salary slips submitted first
  → Verify: Employees have salary structure assigned

Issue: Missing party details
  → Check: Account type is "Receivable" or "Payable"
  → Verify: get_account_type() returning correct type
  → Check: Account master has account_type field set

Issue: Amounts don't balance
  → Check: All components have accounts assigned
  → Verify: Salary component accounts configured
  → Check: No manual edits to salary slips

Issue: Cancellation not working
  → Verify: Not overriding cancel/on_cancel methods
  → Check: Reference fields in JV entries
  → Verify: make_journal_entry() called properly
